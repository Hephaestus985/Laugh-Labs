# Sock Escape

A runaway sock flees the washing machine. Endless runner, made in Godot 4 (4.3 or newer).

## Play
1. Install Godot 4 (e.g. `flatpak install flathub org.godotengine.Godot`).
2. Open Godot, click **Import**, pick this folder's `project.godot`, then press **F5** (or the ▶ button).
   Or straight from a terminal: `flatpak run org.godotengine.Godot --path ~/LLMs/Claude/godot/sock-escape`

## Controls
- SPACE / UP / W / click: jump, press again in the air for a spinning double jump (let go early for a short hop)
- DOWN / S: duck under bubbles, or slam back down mid-air
- ESC: quit

## Difficulty
Speed rises every second. New hazards unlock by score: soap (200), bubbles (600), cats and double ducks (1100), hairdryers (1800), Dryer of Doom (2700).
